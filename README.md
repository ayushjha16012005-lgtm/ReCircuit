# ReCircuit

**Intelligent PCB Component Recovery & Reuse System**

> Smarter recovery, reuse, and circular design for electronics sustainability.

Built by **The InnoveRise** for **Automate India — NIET Chapter**

---

## 🧩 The Problem

E-waste is growing 3–5% every year worldwide, yet most discarded PCBs go straight to material recycling instead of component recovery — perfectly functional parts are shredded along with the scrap. Manual identification, removal, and testing of components doesn't scale to industrial volumes, so the gap between waste generated and value recovered keeps widening.

## 💡 The Solution

**ReCircuit** is an automated pipeline that turns discarded circuit boards into tested, inventory-ready parts. It combines machine vision, robotics, and electrical validation into a single closed-loop workflow — **Scan → Identify → Extract → Test** — so recovery happens faster, more consistently, and without manual bottlenecks.

## ⚙️ How It Works

1. **PCB Input** — a board enters the system
2. **Vision-Based Component Detection** — a camera scans and maps every component on the board
3. **Intelligent Selection** — an AI model decides which components are worth recovering
4. **Automated Extraction** — a robotic arm precisely removes the selected components
5. **Electrical Functionality Testing** — each recovered component is individually tested
6. **Classification & Grading** — components are graded A, B, or C based on quality
7. **Digital Inventory Logging** — every part is catalogued and tracked for traceability
